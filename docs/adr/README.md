# Decision records

Short notes on the decisions that shaped this repo, written at the point they
were made. Each one says what was chosen, what it costs, and — the part that
makes it a decision rather than a rationalisation — what would make me change
my mind.

They're deliberately brief. An ADR nobody reads is worth about as much as a
comment nobody reads.
